## HOW TO USE THIS FILE
1. Go to Google Gemini → Imagine / Imagen 3 (or labs.google/flow for direct image+video)
2. Paste each prompt below to generate the still frame
3. Download each image at highest resolution (1920×1080 or 16:9 ratio)
4. Label each image by its ID (e.g., HERO_01.png, FEAT_03.png)
5. Feed each into Google Flow (File 2) to animate
